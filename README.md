# Frontend - Análise de Empréstimos

Frontend desenvolvido com **Next.js** para o sistema de análise de empréstimos.

## Funcionalidades

- Cadastro de clientes
- Listagem de clientes
- Busca de cliente por ID
- Edição de clientes
- Exclusão de clientes
- Análise de empréstimos
- Seleção das modalidades de empréstimo
- Integração com a API do backend

## Tecnologias

- Next.js
- React
- TypeScript
- CSS
- Fetch API

## Como executar

Instale as dependências:

```bash
npm install
```

## Rodar o projeto
* npm run dev
